OM-D E-M10 Mark III

分类 APS及其以下画幅可换镜头数码相机点评 0 条图片 0 张评测 0 篇

E-M10 Mark III搭载了用于旗舰机型E-M1 Mark II的TruePic VIII数字处理器，内置了五轴防抖系统与Wi-Fi模块，支持高清4K视频拍摄。特设的AP（高级拍照）模式集众多专业、个性化的拍摄功能于一键，即便是面对复杂的拍摄场景，用户也可以轻松面对，体验趣味非凡的摄影体验。
