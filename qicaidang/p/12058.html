LUMIX S1R

分类 35mm画幅可换镜头数码相机点评 0 条图片 0 张评测 0 篇

LUMIX S1R力求实现极致的图像表现能力，搭载了全画幅微单行业内最高水平的4700万有效像素的全画幅（36mm x 24mm）CMOS传感器。相机不仅能再现画面的精美细节，而且传感器拥有非常高的信噪比，聚光效果十分出色。除此之外，高分辨率模式首次应用于全画幅微单相机，可以拍摄高达1.87亿像素的超高清图像。
