XF 23/1.4 R LM WR

分类 APS画幅镜头点评 0 条图片 0 张评测 0 篇

XF23mmF1.4是新一代定焦镜头，旨在支持未来分辨率更高的相机传感器，是XF镜头在图像分辨率方面的新标杆。这款镜头焦距为23mm（等效35mm画幅35mm焦距），极具实用性，有效保障光学性能，即便在F1.4全开光圈下，也能稳定输出清晰度。它能有效抑制弱光条件下的相机抖动和噪点，保证用户的拍摄自由。浅景深效果可渲染虚化背景，实现柔美散景，增添主拍摄对象的立体感。即便在最大光圈下，9片光圈叶片也能够输出近乎圆形的散景效果。这款镜头改善了微距功能，可满足多元化拍摄场景。
