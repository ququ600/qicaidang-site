DP2x

4.41综合评分
分类 不可换镜头数码相机点评 0 条图片 0 张评测 0 篇

DP2x采用了APS-C画幅(20.7×13.8mm)，1406万有效像素FOVEON X 3 (2652X1768X3)真像传感器。添加了AFE系统强化全色彩数据转换为数码讯号前的整合，以获更真色真像的高清影像及加快数据处理时间节省电能以获更真色真像的高清影像。而TRUE II 图像处理引擎提高了图像的处理速度，并且提高了对焦速度。搭载23万像素2.5英寸液晶显示屏。同样延续DP2的24.2mm/F2.8镜头。感光度范围ISO 50-3200（RAW格式可以进行ISO1600～3200的扩展）。连拍速度最高为3张每秒，可以进行320×240分辨率，30fps的视频拍摄。支持SD/SDHC以及最新的SDXC存储卡。
