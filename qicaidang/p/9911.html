COOLPIX L320

分类 不可换镜头数码相机点评 0 条图片 0 张评测 0 篇

采用1/2.3英寸1614万像素CCD传感器，搭载26倍光学变焦镜头，35mm等效焦距达到22.5-585mm。机身后背采用一块3英寸23万像素高清LCD屏幕。支持1280 x 720约30帧/秒高清视频拍摄。内置尼康镜头位移减震影像稳定技术，即使在拍摄短片进行变焦时，也能令影像保持清晰锐利。
