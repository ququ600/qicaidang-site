外媒公布索尼FE35/1.8等三款定焦测试成绩

2019-09-09 · Wayback 存档 · 原站地址

大多数MTF爱好者都知道我们已经按照品牌发布一系列定焦MTF文章。我们还会再添加新镜头的测试结果。最近我们测试了一系列新的定焦镜头，并认为它们也值得放一起。

当然，索尼粉丝已经发布了他们的阴谋理论：“Roger不会公布24mmGM测试结果，因为Roger不想承认24mmGM是如何踢其他人24mm屁股。”然而这些是错误的，这些都是互联网阴谋理论家。索尼24mm f1.4GM推出已经有一段时间了，但老实说，我们在库存方面遇到了麻烦，无法对其进行测试。

我们能够在发货之前抓住第一批索尼FE35mm f / 1.8镜头。 腾龙35mm f / 1.4 SP在我们已经有了一些，但需要一段时间才能将10份副本转移到实验室进行测试。这不是完全披露，我没有敲桌子来测试它们，因为腾龙总是制作好的，但不是最好的镜头。

索尼FE 24mm f / 1.4 GM

从这个镜头发布的那一刻起，索尼用户就失去了他们通常的低调，并大声宣称它是宇宙上最好的24mm镜头。

乍一看，你可能会对该镜头的MTF有点不知所措，但我要指出的是，24mm f / 1.4镜头几乎是最难设计和制作的定焦，并且通常它们没有很好的MTF曲线。 所以我认为这个表现是比较合适的。

例如，索尼24mm f / 1.4 GM与佳能24mm f / 1.4L II对比。 （24mm不是佳能镜头群中最锐利的定焦，但面对24mmGM依然被吊打。）

即使将索尼GM与适马24mm f1.4 Art进行比较，索尼也显然表现的更好。 这是我们测试过的最好的24mm镜头。

但是，这些对比仅仅为了现实测试，让我们记住佳能是一个非常老的光学设计，适马虽然不是很老，但却是最早的Art镜头之一。 在过去几年中，镜头设计有了很多改进，特别是在非球面镜片方面。 出于这个原因，我们想将索尼GM与新的24mm进行比较，但实际上并没有其他新24mm。 我们做了与适马28mm Art的比较，适马这款镜头是最近的设计。 但请记住，由于光学和材料的原因，28mm镜头预计会明显优于24mm镜头。

适马28mm Art更好，但我们将其称之为“24mm和28mm之间的差异”。 而且要非常清楚，适马28mm Art和蔡司28mm Otus是目前最佳广角。 总的来说，我不得不说索尼24mm f1.4 GM是目前最好的24mm镜头，真的是世界级的光学设计。 我还必须指出，24mmGM的价格低于佳能，与西格玛大致相当。 这里没有索尼高价出现，这是一款价格合理的镜头。

索尼FE35mm f / 1.8

接下来是索尼新推出的FE35mm f / 1.8。 对于f / 1.8镜头，它750美元定价比较高，但如果它特别好，那将不是一个荒谬的定价。

乍一看，这显然是一个相当不错的MTF图，但让我们再做一些比较再来看看。 首先我们将它与佳能35mm f / 2进行比较（记住MTF测试 f / 2比f / 1.8更有优势）。 佳能的价格较低，但索尼的f / 1.8比佳能的f / 2好。

下一轮对比，我们将索尼35mm与我最喜欢的廉价镜头之一，腾龙35mm f / 1.8 VC进行对比。 就曲线来看索尼镜头显然表现的更好。

像24mmGM一样，索尼35mm f / 1.8表现非常好。 毫无疑问，索尼最近一直在推出一款又一款出色的镜头，这是在蹂躏第一代和第二代索尼FE镜头。

说到第一代FE镜头，我将这款f / 1.8镜头与索尼35mm f1.4 ZA进行比较。 当然，f / 1.8具有超过f / 1.4 MTF的先天优势。 但你要知道这是一款明显优于700美元的镜头完胜1500美元镜头的对比。 另外请注意，如果你留下关于35mm ZA是多么棒的评论，我们都会意识到你的意思是'在发布800像素自拍之前我不必使用Instagram滤镜来平滑我的皮肤'。

腾龙35mm f1.4 SP Di USD

好吧，到目前为止，我们已经看到索尼在竞争中脱颖而出（即使竞争对手是索尼），但现在是时候看看我期望的“价格合理”的镜头。 腾龙赢得了众多这个评价，我知道这对他们来说很重要，但除此之外，我预计这内容还能体现“物有所值”。

但是，我得到的测试结果是中心锐度出色，边缘保持清晰，矢状线和切线之间的间距很小。所以我们将其与佳能35mm f1.4L II镜头进行了比较。 900美元的腾龙显然比1,500美元的佳能好一点，这使得它比尼康35mm f1.4 G或适马 35mm f1.4 Art更好。

由于前文我赞扬了索尼FE35mm f / 1.8镜头，我决定将这两款镜头进行比较，即使腾龙不适用于FE卡口。与往常一样，f / 1.8镜头比f / 1.4镜头更具优势。尽管有这样的优势，但它们中心绝对是一个平局，但是腾龙在图像的外边缘更好一些。

罗杰的评测结论

与往常一样，我所呈现的只是分辨率测试。我不测试散景、自动对焦速度，或其他任何真正重要的测试。

正如经常出现的情况一样，我的期望是，它不像以前那么正确。我期待腾龙成为一个价格合理的出色的镜头。相反，它目前是光学上最好的35mm镜头，而且价格应该能让你想要得到它。

我认为索尼35mm将比旧的35mm f / 1.4 ZA更好，它是一个极好的小镜头。虽然它为f / 1.8价格设定了新的高点，但我肯定会说它是物有所值的。

索尼24mm f / 1.4 GM与预期一致。对于任何一个品牌来说，这是市场上最好的24mm，并且它的价格合理。

罗杰的妄想

是的，我提出这个词是因为我用一些推测得出了结论。但是，请随意使用它。

在过去的两年左右的时间里，我们已经看到许多镜头制造商在图像质量上做出了惊人的飞跃。适马的28mm和40mmArt镜头远远优于旧的24mm和35mmArt镜头。最近制造的所有索尼镜头似乎都比几年前的索尼镜头更好。腾龙突然抛出了世界级的镜头（SP35/1.4）。 （由于卡口不同，我不打算将佳能RF和尼康Z镜头带入讨论。）

我们知道它们在制造尺寸更大，精度更高、更复杂的非球面镜片上取得了一些进展。我认为非球面镜片的改进也反映玻璃镜片更精确的成形和抛光工艺。而且我知道在光学机械方面取得了长足的进步;更准确地放置镜片并精炼如何调整这些镜片以获得最佳光学质量。

最重要的是，在这个时刻，您通常可以确定最近设计的镜头在光学上优于十年或更久以前设计的镜头。 2010年，我们都在等待下一个更高分辨率的传感器。那些传感器分辨率提升似乎正在放缓;但也许镜头分辨率提升更为显著。
