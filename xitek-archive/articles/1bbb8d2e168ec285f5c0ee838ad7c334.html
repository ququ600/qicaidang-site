外媒公布适马35/1.2Art的MTF测试结果

2019-12-03 · Wayback 存档 · 原站地址

我们刚刚完成了对适马35mm f / 1.2 DG Art定焦镜头的测试，并给人留下了深刻的印象。 一周前我宣布腾龙35mm f / 1.4 SP是我们测试过的最锐利的35mm镜头，因此我们很好奇在测试适马之后该称号是否还会成立。

实际上，我是如此好奇，以至于违反了我们测试MTF的规则（以往只测试最大光圈）。 我们在f / 1.2和f / 1.4下都测试了适马这款镜头。 为什么最终让我违反了规则？ 因为我有充分的理由并且正在进行神圣的探索，今后是否会再次打破它？ 不！

让我们花点时间快速比较适马35mm f1.2与其他35mm定焦镜头（包括一些用于其他卡口镜头，因为很多人在索尼相机上转接其他卡口镜头拍摄）。

显然，如果最大光圈不是那么重要，那么索尼FE 35mm f1.8可以提供更小巧镜身，并以较低的价格提供出色的成像质量。 许多人可能没有意识到适马 35mm f1.4 Art是最便宜的选择，但仍提供出色的分辨率。 最近测试的腾龙35mm f1.4 SP在这个焦距下是分辨率的冠军，而且价格便宜。

但是，适马 35mm f / 1.2可以使您达到f / 1.2，而我们中的某些人至少在达到f / 1.2之后才有欲望购买。 您为f / 1.2付出了代价，包括美元和镜头尺寸。 那又是什么呢？ 因为我们都知道很多f / 1.2镜头都“大光圈，锐度保持一般”。

MTF测试结果

对于f / 1.2镜头来说，MTF图非常好。 中心分辨率非常好。 尽管偏离中心其分辨率仍有较好表现，且仍保持了良好的径向和切向分离，这表明有些散光等。 不过，这是非常适合大光圈镜头的，而且并不严重。

由于我们都习惯查看f / 1.4 MTF图，因此有必要与其他一些f / 1.2比较，以显示适马这款f / 1.2镜头的清晰度。我们其他35mm f1.2仅有的数据是Voigtlander Nokton 35mm f1.2 Mk II。 Voigtlander是一款较旧，较小，较便宜的手动对焦镜头，因此我们没想它会比得上适马。 事实也是如此。

经典的老款佳能50mm f / 1.2L是f / 1.2镜头，虽然它不是35mm焦距，但仍然值得比较。 但是，即使在过去，这款佳能镜头也从未被视为锐利的镜头。 （我们还不能测试RF 50mm f / 1.2，所以没法比较。）

我之前测试过的最锐利的广角镜头是Leica Noctilux-M 75mm f / 1.25 ASPH。 尽管徕卡的价格为12,000美元，适马和它比确实更锋利。 老实说，对此我感到有些惊讶。

因此，我认为我们已经解决了适马是否是我们测试过的最锐利f / 1.2定焦的问题。 （从计算机生成的MTF图中，我确实认为佳能RF 50mm f / 1.2可以展现更清晰的表现，但正如我所说，我们尚无法对其进行测试。）
