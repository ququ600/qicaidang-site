金士顿19合1读卡器

2007-12-20 · Wayback 存档 · 原站地址

全球第一大独立内存模组制造商——金士顿科技，今日强力推出十分符合市场需求的19合1读卡器，消费者将可以更加容易地读取及储存不同规格的闪存卡。这款新推出的19合1读卡器是一款外接式、高速读卡器，可以支持19种主流闪存卡规格，现已上市。无需转接器或电源线，这款新推出的读卡器是在闪存卡和计算机或其它设备之间轻松传输文件的绝妙设备!

“现在许多人拥有多种不同规格闪存卡来搭配自己手机、数码相机、计算机或其它设备使用，在不同的设备之间进行数据、音乐、照片、视频等文件的传输，新推出的金士顿 19合1读卡器支持多种不同的闪存卡规格，将成为此消费群的一大利器。容易携带的特点将使其成为大家旅行或是工作中的绝佳帮手。”金士顿大中国区数码产品经理王立平表示。

金士顿 19合1读卡器（产品料号：FCR-HS219/1FE）设计了4个内置插槽以支持多种不同的闪存卡规格，并有一个独特的伸缩式外壳来保护插入的卡片，使其不易受到损害。此外，它自带有一条3英寸的USB连接线，可以和笔记本店你或其它便携式设备的USB接口相连，相当容易使用。另附送一条3英尺长的USB延长线，让消费者方便在家中和办公室中使用。

金士顿 19合1读卡器享有2年保固以及免费技术支持服务。

功能和优势：

• 伸缩式外壳：内建LED指示灯，附有3英寸USB线（Type A插头） • 容易携带：小巧方便，无需电源线 • 附赠延长线：附赠3英尺长的USB延长线，方便在固定场合使用 • 通用性：四个插槽支持19种不同规格的闪存卡：CompactFlash® Type I/II, SD™, SDHC™, miniSD™, miniSDHC™, microSD™, microSDHC™, MMC, MMCmobile™ (DV RSMMC), MMCplus™, MMCmicro™, RS-MMC, Microdrive;同时支持Memory Stick® Micro (M2), Memory Stick®, Memory Stick® PRO, Memory Stick® Duo和Memory Stick® PRO Duo* • 标准化：符合USB 2.0标准要求，兼容USB 1.1 • 易用性：随插即用，支持USB 2.0和USB 1.1接口

特点：

• 尺寸大小：91.72×68.82×20.06mm • 速度**：USB 2.0，最高达480Mbps • 操作温度：0º～60ºC • 储存温度：-20º～85ºC • 重量：71g • 操作系统兼容性：Windows 2000 (SP3或更高版本)、XP (SP1或更高版本) and Vista™; Mac OS (10.x或更高版本) • 保固服务：2年保固 * 此处提及的所有品牌和产品名称仅以辨别为目的。Memory Stick和Memory Stick PRO Duo是Sony公司的商标。金士顿并非Sony公司的分公司。其它产品名称均为其所有者的商标或注册商标。 ** 因设备设置不同，速度可能会随之改变。 产品特点如有变更，恕不告知。
