各家70-200mm f/4镜头MTF大比拼

2019-08-02 · Wayback 存档 · 原站地址

之前lensrentals给出了各家70-200mm f / 2.8镜头MTF图表，本次该网站列出了各家f / 4版本的MTF图。 体育和肖像摄影师需要f / 2.8光圈，但我们当中许多人，大多数时候更愿意购买更轻便的f / 4镜头。

所以，关于f / 4

在我们开始之前，先要纠正某人在互联网上看起来愚蠢的观点。有人用我们的MTF图表说“f / 4实际上比f / 2.8更锐利”，或者“f / 2.8比f / 1.4更锐”。

那么让我们快速看看f / 2.8到f / 4的区别。 我们将以佳能70-200mm f / 2.8 IS II为例。 以下是在f / 2.8和f / 4下的70mm处的MTF结果。

你可以看到几乎所有画面范围内70mm端收缩光圈都有一个非常显着的改进。

我们在200mm处进行相同的比较。 与70mm端有点不同。 在收到f4，图像中心明显更清晰，但在画面边缘部分，没有明显的改善。 曲线虽有不同，但并不是更好。

那么为什么我必须打破你对“大三元”的追求，只需给我一个数字就可以在所有焦距、光圈和拍摄条件下评估整个镜头，这样我就可以上网并说某品牌70-200mm得分74.2好于某品牌70-200mm的73.7分？

改善的原因非常简单。请记住，镜头受到像差影响，其中包括降低MTF。通过收小光圈，一些像差会得到显着改善或改善。距离中心越远，由于其他像差也明显越差，并且不会因收缩光圈而受到太大影响。

因此，收缩一档光圈将使图像的中心产生巨大差异;与光圈孔径相关的像差（主要是球面像差和有一些彗差）得到​​改善。

在图像的边缘处，收缩光圈会对许多像差产生一些影响，但对其他像差却没有什么变化。除非您知道镜头有哪些像差，否则您无法预测收光圈会有多少改善，特别是在图像的边缘部分。

我总是喜欢当有人在网上搜索“边缘肉甚至不改善，所以我的镜头有缺陷。”无论你收到多少光圈，很多镜头都不会在边缘变得非常锐利，变得像在中心一样锐。

因此，让我们进行更实际的测试，并将f / 4的70-200 f / 2.8 IS II与70-200mm f / 4 IS II进行比较（后面将显示完整的f / 4曲线）。

在这个例子中，我们可以看到虽然f / 4全开要比f / 2.8镜头全开稍微锐一些，但它并不比收到f/4时的f / 2.8镜头更锐利。

另一个的信息是你不能确切地知道变焦镜头会在收到多少或到哪里，镜头会更好，但如果没有测试，很难准确预测好多少。 我们没有资源在所有变焦上做收光圈测试。 即便是这个小小的3个例子也花了一天的时间进行测试，周期时间并不足够做更多测试。
