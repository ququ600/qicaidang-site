时尚复古，小巧全能-佳能PowerShot G1 X Mark III 评测

2017-12-26 · Wayback 存档 · 原站地址

今年10月佳能发布了PowerShot G 系列新旗舰机型 PowerShot G1 X Mark III（后文简称 G1 X Mark III） 。时隔3年，相比前一代G1 X Mark II ，G1 X Mark III在各方面都有较大的提升 。

首款搭载 APS-C画幅固定 变焦 镜头的便携式相机

G1 X Mark III相比前一代有许多变化，首先G1 X Mark III减轻了机身的重量、体积，添加了236万点电子取景器，搭载了佳能的DIGIC 7影像处理器，COMS从之前的1.5英寸变成了APS-C 画幅，同时也是PowerShot 系列里首款搭载全像素双核对焦的机型。似乎在纸面参数上，G1 X Mark III和佳能的M系列旗舰 M5 已经没有明显区别。

详细参数

从参数信息来看，G1 X Mark III的参数配置相比前代来说，提升还是较为明显的 ，不仅采用了佳能2420万像素APS-C CMOS以及DIGIC 7处理器。同时也是该系列首款搭载全像素双核对焦系统的机型 ，单次自动对焦下连拍可达到9张。相比G1 X Mark II，G1 X Mark III常用感光度提升到 ISO 100-25600，体型上也更加小巧，有更好的便携性。
