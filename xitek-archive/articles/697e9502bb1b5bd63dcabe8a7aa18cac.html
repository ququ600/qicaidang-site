DxO公布适马24-70/2.8Art测试成绩

2018-02-07 · Wayback 存档 · 原站地址

整体镜头图像质量

适马24-70mm f / 2.8 DG OS Art（佳能口）在5000万像素的佳能EOS 5DS R上总体评分为30分，其上代为26分。从测试结果表明适马拥有更低的横向色差; 不过，这款Art系列镜头的锐度比其他竞品略低。 尽管边缘清晰度较好，但由于某些散光，水平限制了24mm，在70mm处更加明显，锐利度反而下降。 它在35mm和50mm焦距之间的变焦范围中可获得最佳效果。

与其竞争对手对比的图像质量

适马 24-70mm f / 2.8 DG OS HSM A的性能与主要竞争对手非常接近。不过，其30分总分略低于同价位腾龙SP 24-70mm f / 2.8 Di VC USD（2012年）和图丽AT-X 24-70 F2.8 PRO FX（2014年）。适马不敌佳能EF 24-70mm f / 2.8 L USM II，佳能更加锐利、更好的通光量、色差也相当低。考虑到我们对ART系列的期望，这有点意外。

深入比较

在本节中，我们适马与腾龙SP 24-70mm f / 2.8 Di VC USD G2、佳能EF 24-70mm f / 2.8 L USM II对比。使用全画幅5000万像素佳能EOS 5DS R测试了这三款镜头：

锐度

当把这款镜头与以往产品时，我们可以看到适马在外部三分之一处的清晰度得到了提高，特别是在焦距范围内的f / 2.8处，但是在比较这个时并不那么有说服力。我们在图像的中央三分之二处检测到24mm处的散光（水平和垂直的锐度线并不总是接近）。清晰度水平在整个画面上不会落后于腾龙或佳能，但在边角仍不行。

在70mm处，散光也是一个问题，锐化水平已经远远低于佳能，甚至远低于腾龙。适马在50mm范围内表现最好，与竞争者差距不算太远，即使如此在影像领域的三分之一的地方仍然不行。上图的锐度分析显示了三个镜头在最长焦距和f / 2.8下的清晰度。收缩光圈f / 5.6-8会增加锐度。此后适马开始受到一些衍射影响，得分较低。

色差

正如我们在这款镜头尼康口评测中讨论的那样，适马Art比其上一代镜头显着减少了色差，在24-28mm的焦距上限制了较高的程度（一般在10微米以上），这是最难纠正的。

虽然佳能和腾龙在24mm和70mm焦段都有更好的控制。 令人惊讶的是，腾龙在这方面比佳能修正的更好，特别是在50mm时，对于佳能来说，是最明显的且最薄弱。通常 软件可以消除RAW文件的色差，但是对清晰度的影响可能是难以弥补的。

畸变

在我们的测试中，适马对畸变的控制相当好。 它24-35mm与佳能处于相同的桶形畸变水平，中焦距的枕形畸变处于较低水平。 另一方面，适马的主要竞争对手腾龙，在24mm（+ 0.9％）的情况下，比其他两个竞争对手都有更高的桶形畸变。 但50mm到35mm之间有很好的校正，与佳能和适马在70mm的相同水平（-0.5％）。

暗角

适马在变焦的两端展现了与腾龙类似的暗角水平。 从我们的测量结果来看，在70mm处的剖面几乎相同。 不过，佳能24-70的24mm在三款拥有最明显的暗角，在70mm处与适马和腾龙类似。 下图显示了三个镜头的最广焦距和最大光圈（可能最明显）暗角程度。

有预算意识的选择

对于预算紧张的买家而言，300美元适马这款并不值得考虑，还有一个选择。例如图丽AT-X 24-70mm f / 2.8 PRO FX零售价仅有950美元。如果您可以接受稳定性和广泛性的损失，它具备与适马类似的整体性能，甚至峰值清晰度稍高，光通量更好，色差控制也良好。

结论 ：佳能用户的坚实选择

适马的ART系列大多提供的光学质量与最好的产品相媲美。虽然适马 24-70mm f / 2.8 DG OS HSM A在光学上与前代相比有所改进，但目前无法与佳能EF 24-70mm f / 2.8L II USM相提并论，品质只能和（2012年）腾龙SP 24-70mm f / 2.8 Di VC USD（已经更新G2）相当。

尽管如此，适马24-70mm f / 2.8 DG OS HSM仍然有不错的表现，我们仍然认为它的整体表现很好。它在所有焦距范围内具有相对均匀的清晰度，而色差、畸变和暗角都得到很好的控制。

在这个评测中，适马24-70mm f / 2.8 DG OS HSM A与尼康、腾龙直接竞争对手进行了比较。像往常一样，您可以使用我们的交互式镜头比较工具创建自己的比较和深入的分析。
