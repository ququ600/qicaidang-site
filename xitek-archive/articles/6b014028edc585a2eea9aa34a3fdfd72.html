点评5DⅡ的视频功能（3）

2008-12-17 · Wayback 存档 · 原站地址

首先是分辨率。我们都知道电视成像是通过扫描形式，一个点一个点一行一行地扫描。在没有高清电视以前都是隔行扫描，到DVD的末代才加上逐行扫描。我们先把这个差别忽略不计，比较一下普通电视、DVD、和高清电视的分辨率。

PAL制式（欧洲、中国、香港等）电视广播信号最多有625行（欧洲是576），NTSC制式（北美、日本等）是525行。按照电视4：3比例换算横向共有833点，相当于833 x 625；NTSC则有700 x 525。然而实际我们能够看到的模拟电视广播不可能看到这么多信息，因为这些信号中还有一些被广播商拿去播放其他信息，再加上电视机屏幕上下左右部分会有变形边缘一些信息会被舍弃（overscan）。

此外因为模拟电视信号本身的缺点，加上隔行扫描，实际上我们最多只能得到300线左右的分辨率，大约为400 x 300。

DVD视频光盘把这些信息用数字方式记录下来，因而减少了广播过程中产生的干扰，可以把分辨率提高到接近PAL/NTSC的极限，尤其是前面提到的逐行扫描（progressive scan）技术。

曾经在中国大陆广泛流行的VCD分辨率更低，NTSC是352 x 240，PAL是352 x 288。

进入高清时代，图像分辨率形式就更多了，目前使用比较广泛的有：

480P

704 x 480

576P

704 x 576

720P

1280 x 720

1080I

1280 x 1080, 1440 x 1080

1080P

1920 x 1080

这里的I是隔行扫描（Interlace scan），P是逐行扫描（Progressive Scan）。有关这两者的区别暂时不讨论。同时，低于720P以下的被称为标清（Standard Definition），而从720P（720i － 很少用）开始的被称为高清（High Definition）。鉴于部分厂家过去的一些市场行为，后来还多了一个全高清（Full-HD），就是指最高能够显示1080P的电视机。目前市面上还有相当多的平板电视不支持全高清，这是另外一个话题。

如果各位有观看高清电视地面信号广播的话，中国大陆目前使用的是1080i.
