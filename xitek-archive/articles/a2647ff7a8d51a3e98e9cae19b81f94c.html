全能多面手——佳能70-200mm F4L IS II USM试用

2018-08-19 · Wayback 存档 · 原站地址

镜头的焦段有很多很多，如果要说哪个焦段最经典，估计这个话题永远也说不完。但是要说那个焦段镜头是职业摄影师必入的话，编辑认为这就是70-200mm这个焦段，这个焦段可以完成多数题材的拍摄，可以说是镜头里的万金油一般的焦段。

2018年的6月初佳能发布了最新的EF 70-200mm f/4L IS II USM镜头，相比光圈2.8的70-200mm，F4的镜头在重量轻便、体积小巧很多，便携性上大大提高。接下来我将谈谈这段时间，编辑在试用这只镜头的感受，首先先来看看新镜头对比前一代的参数上的变化。

表格

对比前一代，两者体积上几乎无异，新镜头的最近对焦距离由之前的1.2m变为1m，镜头的放大倍率提升至0.27倍，这意味着长焦端下将会有更好的虚化，并且光圈数由之前的8片增加到9片，拍摄时会得到更加柔和的焦外。总体上是继承前代的优点，改进了一些不足。具体信息我们后文详细分析。

1.优秀的解析力

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/160秒 ISO1600

（蓝色为UD镜片、绿色为荧石镜片）

新款镜头依旧采用了两片UD镜片和一片荧石镜片的设计，荧石镜片可以有效的补偿镜头的色差，保障所拍摄的图片的分辨率和对比度。虽然镜组结构和前一代比起来没有变化，但是镜头镜片位置还是有细微的调整，使得最近对焦距离和放大倍率的提升，镜头的成像也有所提升，即使使用佳能 EOS 5DS/R这样的高像素机器也能有出色的表现。

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/500秒 ISO4000

（100%放大截图）

即使在ISO4000的情况下，将图片百分百放大，依旧有不错的细节表现。光圈全开中心锐度也很出色。当然如果你想要更好的成像质量，可以搭配佳能的5D4或者5DSR等高像素机器进行拍摄。

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/80秒 ISO1000

（100%放大截图）

上图是编辑拍摄的路边小猫，使用200mm拍摄可以和小猫保持一个安全距离，小猫也不会被你吓跑。凭借镜头优秀的画质，编辑也当了一次数毛党。将图片图片百分之百放大，猫咪的胡须也是清晰可见，锐利无比。 总体上来说佳能这支70-200F4的解析力十分优秀，无论是光圈全开还是在小光圈下中心边缘表现出色。

2.出色的对焦

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F8.0 1/2000秒 ISO1000

佳能EF 70-200mm f/4L IS II USM 有着出色的对焦性能，即使在超高速的赛车比赛中，新镜头对焦上一点都不迟疑。 这都得益于镜身的USM对焦驱动，自从1987年以来佳能首次将USM环形对焦用于EF 300mmF2.8 USM上，佳能的长焦远摄镜头几乎都搭配该对焦驱动至今，环形USM本身具备较强的扭矩，可以较好的驱动镜组对焦，并且十分的迅速且安静。

（usm环形驱动)

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/500秒 ISO160

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/4000秒 ISO320

赛车的移动速度很快，有时候一没注意车子就从你面前风驰而过，拍摄这类题材很考验镜头的反应速度。编辑使用 EF 70-200mm f/4L IS II USM 搭配佳能1DX II拍摄，明显感受到新镜头从远处到近处对焦反应很快，搭配佳能强大的1DX II拍摄高速运动丝毫没有问题。

3.优秀的抗眩光

新镜头使用ASC镀膜技术，该镀膜对空气的折射率要低于光学玻璃，可以有效的抑制镜片和空气边界的反射，根据佳能官网的对比图可以发现在逆光环境下新一代镜头可以有效抑制眩光和鬼影。

根据编辑实际使用，在逆光环境下镜头对炫光和鬼影的抑制相比前一代是有明显的提升。并且新镜头的光圈数由之前的8片提升到9片，这样可以有效提升点光源的虚化，长焦端下焦外相当柔和。

4.五级防抖，多种防抖模式

佳能官网数据显示，佳能EF 70-200mm f/4L IS II USM配备了IS影像稳定器单元，有效提高了处理速度。根据CIPA标准显示该镜头在200mm时搭配佳能1DXMark II 可达到五级防抖，理论上在200端下的安全快门为1/6秒左右，这意味着在光线较暗的环境下，使用该镜头也能拍出清晰的照片。

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F9.0 1/80秒 ISO500

新镜头搭载三种防抖模式，模式1为日常拍摄静态物体用的，模式2可以下拍摄赛车等规律运动时，模式3用来拍摄不规律运动比如篮球、足球等。

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F16 1/50秒 ISO100

编辑使用模式2拍摄CHINA GT北京站比赛，手持 EF 70-200mm f/4L IS II USM拍摄，面对超高速的赛车，快门在50分之一秒仍可以做到车身清楚，背景模糊的动感效果。

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/15秒 ISO2400

通过编辑实际测试，在200端下1/7秒左右也可以拍摄较为清晰的照片，但是相对来说成功率较低，缩回到4级左右使用1/15秒拍摄，会有更好的效果，更好的成功率。所以一般情况下还是不要挑战极限稳定。

5.最近对焦距离

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/500秒 ISO160

之前有提到佳能70-200mmF4 虽然镜头的镜组结构没有变化，但是镜片位置有轻微变化，使得相机的最近对焦距离对焦距离由前一代的1.2米缩短至1米，在200端下镜头的最大放大倍率也提升至0.27倍。

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/3200秒 ISO1000

由于最近对焦距离的缩进，最大放大倍率的提升，拍摄者可以离得更加近的距离拍摄，突出主体物，实现更强的视觉效果，利于人像、花卉拍摄。

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/80秒 ISO1000

6.全面的焦段，轻量化的设计

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/8000秒 ISO3200

恒定光圈的变焦镜头下，大致分了F2.8和F4两个挡位。但是F2.8的镜头体积上太大，EF 70-200mm f/4L IS II USM采用轻量化的设计，镜头净重仅为780g，相比前一代虽然重了20g，不过实际使用两者没有明显区别，编辑搭配佳能6D II出门扫街很轻便，并且使用长焦拍摄并不会打扰到被摄者，长焦下背景的压缩可以得到不一样的视觉效果。

EOS-6D Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/100秒 ISO5000

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/250秒 ISO800

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F4.0 1/800秒 ISO4000

结论

EOS-1D X Mark II / EF 70-200mm f/4L IS II USM / F10 1/1600秒 ISO4000

通过近期的使用，总体上这支镜头依旧延续F4L镜头群的小巧轻便的外观，新的镀膜技术的加入使得镜头在逆光环境下表现出色，最近对焦距离离近了20cm，最大放大倍率的提升确保了优秀的成像质量。70-200mm的焦段可以拍摄任何题材，全天候的镜身可以在任何环境的拍摄，加上出色的对焦性能，优秀的防抖效果，总的来说佳能EF 70-200mm f/4L IS II USM各方面表现都很出色。 售价方面和前一代上市时相差不大，相对F2.8价格也更具性价比，如果你需要一支70-200mm的镜头，但是有没有足够的预算购买F2.8的镜头话，佳能EF 70-200mm f/4L IS II USM这支头是很不错的选择。
