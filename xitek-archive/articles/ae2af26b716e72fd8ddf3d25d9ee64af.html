金士顿大容量存储卡

2008-08-04 · Wayback 存档 · 原站地址

在一张小小的卡片中，收藏音乐、图画、照片、文件、报告，我们所能想象的到的，都因为“存储卡”这张小小的移动数码产品的诞生，被压缩、被轻松装载还有随意携带。当存储卡容量的大小开始成为评定一枚卡片身份的标志，当读写速度成为提升数码产品表现的功臣，我们在一代代卡片的新旧更替中，感受到最多的就是科技的魅力。

大容量存储卡究竟为生活带来了怎么样的改变？我们又将在大容量存储时候里如何游刃有余的开启移动存储生活呢？我们不妨随着金士顿多款大容量存储卡的“舞台秀”，让科技征服一下我们的想象。

8GB microSDHC 独领风骚

提到金士顿大容量microSDHC闪存卡，没有人不会赞叹科技的魅力。一张指甲大小的卡片，却可以收容数部电影、近千首MP3，甚至在用手机拍照的时候，流畅的让人惊叹。继推出4GBmicroSDHC存储卡后，金士顿全新的8GBmicroSDHC的上市，更加颠覆了我们对手机内存卡的想象。

金士顿8GB microSDHC闪存卡

它的速率规格达到了Class 4，也就是说金士顿确保了这张卡片的最低数据传输率为4MB/秒。而这只不过是标称数值而已，实际测试下来，发现它的实际读写速度远高于4MB/s，写入速度达到了8.3MB/s，而读取速度更是达到惊人的20MB/s。可想而知，有如此高速的读写速度，无论数码相机、摄像机、手机还是MP4播放器等数码设备，都将在大容量与高速读写的闪存卡支持下，发挥出全部性能。

读写速度非常惊人，远远超过标称数值

大容量SDHC 存储无限可能

大容量SDHC卡片的广泛应用，无论是对于拥有数码相机的家庭用户、摄影爱好者还是专业摄影师来讲，都具有非凡的意义。大容量SDHC卡片突破了传统SD卡的容量限制，用更大的存储空间帮摄影者将无限影像收藏。但对于这些永远走在路上追求美景的人来说，大容量永远都不够。金士顿SDHC 16GB Class 4闪存卡，和容量翻了一倍的SDHC 32GB Class 4闪存卡的推出，用超大的容量和极佳的传输速率，让专业摄影师折服。而金士顿SDHC 8GB Class 6闪存卡，最低6MB/秒的传输速率让数码产品的表现更加出色，8GB的存储容量同样不可小觑。可以简单计算一下，现在民用级1200万像素的数码相机所拍摄的照片约为3MB/张，那么32GB的存储卡将能够存放1万张以上！这样一来，甚至可以不必再将照片导出到电脑，干脆将所有照片以不同的文件夹保存在卡上，无论是浏览、整理照片还是与亲友分享，都比现在方便很多。

金士顿 32GB Class4 SDHC闪存卡

CF卡宝刀不老

同样，作为存储卡的“老前辈”，CF卡而今依旧有着一定的市场，大容量的CF卡同样在存储卡历史的舞台上扮演者不可或缺的角色。金士顿16GB CF卡和8GB 极速CF卡就是大容量卡片的代表。最值得一提的是金士顿8GB 极速CF卡，它拥有266X的写入速度，写入数据传输率高达40MB/s，可以帮助用户更加快速的捕捉连续变幻的影像。Media RECOVER数据恢复软件的应用，更确保了文件的安全性，避免了文件的丢失或损坏。

金士顿266X CF 8GB闪存卡

套装组合+多功能读卡器 各显神通

科技之于人类的最终目的，是要为我们的生活带来更多的便利。在便捷的科技应用上，金士顿一直都不断为消费者带来惊喜。在金士顿的移动存储家族中，包括microSD卡+miniSD/SD适配器套装组合、4GB microSDHC卡+MS Pro Duo*适配器套装、4GB MBLY移动存储套装以及19合1读卡器等产品在内的多款“综合实力”强大的全能选手，大大的提升了金士顿的各种产品在当前多种设备平台上的兼容性和通用性，将最实惠、最便捷的科技体验带给消费者——让记忆棒与存储卡之间成为兄弟，也让不同规格的卡片在一个包容的读卡器面前不在感到身份的尴尬。

金士顿 MBLY移动存储套装

大容量存储卡 让存储无所不能

见识了这么多金士顿的新款大容量闪存产品，我们发现，大容量存储卡正在引领着新的存储时代的到来。当卡片的容量增加以后，到底该怎么玩才够酷呢？这时候，恐怕随身的PSP就成了家庭影院；手机变成了能存储上千首歌曲的MP3；数码相机摇身变成影像博物馆；外出旅行再也不用背上砖头一样的笔记本，轻松的数字生活便在小小的卡片中开启。

这就是金士顿开启的大容量存储时代，用技术与梦想征服你的想象。
