1英寸杀手？我眼中最好的便携相机 松下LX100 Mark Ⅱ体验

2018-09-17 · Wayback 存档 · 原站地址

在很多语境下，最好的相机归属给谁，都是不恰当的。但是如果说在我的眼中，最好的便携相机是LX100 Mark Ⅱ，我相信我自己是不会反驳的。

松下LX100作为开创者，已经收获了好几车的赞誉，只不过产品更新频率没有参与到便携相机市场残酷的绞杀战中。随着索尼不断加码和营销，索尼黑卡成为了便携相机市场上声量最大的产品。

但是随着LX100 Mark Ⅱ的发布，我眼中最好的便携相机迅速易主。

首先来看LX100 Mark Ⅱ的主要参数：

2177万像素传感器 有效像素1700万 等效24-75mm F1.7～F2.8镜头 11张/秒连拍速度 276万点EVF取景器 3.0英寸124万点触控LCD 30p/25p UHD 4K视频 支持4K照片 支持后对焦技术 支持WiFi&蓝牙连接 支持USB充电

外观及操控

外观基本和前代基本没变化，但是仍然硬上解析一遍。因为毕竟还有对前代LX100本身就不是很了解的用户。

正面可以看到体积比例不小的镜头组，这也是得益于4/3画幅，镜头可以尺寸稍大，来保证镜头的最大光圈可以做的更大一些。此外LX100 Mark Ⅱ顶部热靴插着套装内的闪光灯，比例仍然非常协调。

这支等效24-75mm的镜头光圈为F1.7～F2.8，镜头物理体积没有被浪费，镜头上搭载了对焦环、光圈环、对焦切换拨杆、画幅切换拨杆，方便操控。尤其是镜头上方的画幅切换拨杆，可以快速的在1:1、4:3、3:2、16:9四个画幅比例间切换，免去进入菜单调整的步骤。

顶部拨盘可以看到带A挡、T门的快门速度拨盘、W&T变焦拨杆、曝光补偿拨盘、Fn按键以及iA智能模式按键。整体按键的排列较为紧凑，但并不乱，下意识的操控也非常容易上手。

从实际体验来说，LX100 Mark Ⅱ以及前代的工程学设计简直满分，虽然只是一台小巧的便携相机，但是单手操控完全无虞，尤其是曝光补偿拨盘在机身靠后、外侧的位置，拇指很轻松的就可以拨动，而且阻尼良好，并不会有太多误处的问题。

W&T变焦拨杆可以提供还算不错的变焦速度，电机驱动镜头变焦的时滞也很小，随拨随动，随拨随停，虽然看起来是一个面向入门用户的设计，但实际体验起来并没有什么不灵活的问题。

背面保持了利于单手操作的布局，和一代的按钮操控体验并没有太大差距，主要明显升级是这块新的LCD屏幕，提升了像素并且支持了丰富的触控操作，美中不足的是EVF取景器的眼点距离和刷新率等方面，还是没有什么改动，如果有更广阔的视野和再高一点的放大倍率，EVF取景就更舒服了。

操控方面来说，LX100 Mark Ⅱ给人一种感觉并没有什么特别的设计，但是整体操控体验非常流畅，大部分最常用的操控都可以通过物理按键快速的完成操作，而不需要进入菜单调整。LX100 Mark Ⅱ比起其他1英寸略大一点的机身，可以有更多空间进行灵活的布局设计，这也是LX100 Mark Ⅱ比许多1英寸便携相机“操控”更优秀的地方。

一方面有足够多的物理按键，一方面机身体积较为宽裕的情况下，握持起来拇指、食指的运动空间都非常从容，不会出现很局促的问题。而实际上LX100 Mark Ⅱ相对于1英寸便携相机的体积来说，并没有什么令人难以接受的大，在便携和手感间有非常好的平衡。

侧面接口最值得说的就是，LX100 Mark Ⅱ支持USB充电了，可喜可贺！

画质及体验

新传感器新起点 提升像素 画质更佳

LX100 Mark Ⅱ在机身外观和镜头方面没有特别明显提升的情况下，CMOS的变化当属最大的提升。原先传感器有效像素仅为12mp万，而现在采用了主流20mp万像素的传感器，有效像素达到了17mp。有效像素提升了500万像素，对于画面精细程度、二次剪裁余地都有很大的提高。当然新的维纳斯引擎也提供了新一代水准的处理性能和新的算法，在JPG画质以及降噪方面也有助力。

对于松下LX100 Mark Ⅱ的拥趸来说，很多用户都期待这一代不再采取画幅剪裁设计，不过如果要采用完全4/3画幅成像面积机身和镜头的尺寸势必无法保持现在的紧凑和小巧，因此我认为这样的妥协在目前来看是值得的。

MOS分辨率的提升，当然的带来画质的改善，LX100 Mark Ⅱ的广角端和长焦端画质都有肉眼可辨的提升。

而采用更新的传感器，LX100 Mark Ⅱ的高感光度表现也有不小的提升，ISO3200~ISO6400都进入了完全可用区间，当然噪点仍然存在，但是已经不属于“声嘶力竭”的将暗部提亮，从而带来大量的彩噪。现在的LX100 Mark Ⅱ在夜间或者室内，ISO3200并不会产生让你非常难受的噪点，ISO6400的涂抹保证你发布在社交平台和网络相册上的照片，也不会有明显的大面积损失细节的涂抹。

其他方面来说，LX100 Mark Ⅱ支持松下4K全家桶系列，例如4K视频、4K连拍，后对焦等技术基本上和旗舰机型基本上是完全相同的水平。

镜头浮动镜片设计 画质更好 合焦更快

在机身和镜头规格没有太大修改空间的前提下，升级CMOS是题中应有之义，而镜头也有一定的优化，采用了浮动镜片设计，确保在整个镜头的焦距覆盖范围、对焦距离内的画质一致性，一定程度上也提升了整体的画面表现。从主观感受来说，LX100 Mark Ⅱ的长焦端画质比起前代提升较为明显。

镜头的对焦一是得益于薄膜镜筒等轻巧镜头设计的底子，镜片很紧凑也很轻量化，足够强劲的电机可以确保镜头迅捷的合焦速度。同时松下一贯的高刷新率MOS，让这台便携相机的对焦感受非常出色，在街头基本上可以做到随手乱拍，合焦都不用担心的。

等效24mm~75mm，光圈F1.8~F2.8，但从参数来看，和许多1英寸便携相机并没有太大差距，但是由于前面提到4/3画幅的传感器，镜头的分辨率以及和镜头虚化强度，都要比1英寸有较为明显的优势。这是LX100 Mark Ⅱ继操控优势之外，同样对1英寸产品有竞争力的优势之一。

新增L.单色D模式 风味独特的黑白滤镜

单色模式是LX100 Mark Ⅱ之前就搭载的功能，这次在LX100 Mark Ⅱ更新的是L.单色D模式，有了反差更大以及可调更粗粒的颗粒表现。说实话是目前松下内置的色彩风格中，最有趣的一个滤镜模式。LX100 Mark Ⅱ搭载的其他颜色滤镜基本保持了传统的松下风格，JPG在晴天略有偏品色的风格。

实际拍摄下，不论白天黑夜，升级后的单色滤镜都有不错的表现。反差比之前的单色模式有更明显的提升，也让数码的灰色过度更为自然。虽然并非特别高反差的黑白模式，但亮部和暗部的对比仍然有很强烈的对比，同时暗部的细节保留比绝对的高反差模式更丰富，不至于暗部细节完全丢失。

体验过程中，LX100 Mark Ⅱ的许多滤镜中，单色滤镜更吸引我，大部分场景下我都愿意采用这个模式，体验下松下的黑白味道。再此之前，松下并不是以黑白滤镜见长的品牌，理光GR的高反差黑白和富士的ACROS都各自有各自的拥趸，而我也长时间的体验过理光GR风格的高反差黑白和富士ACROS细腻黑白滤镜，和这两个滤镜对比，松下的L.单色D直出其实也别有风味。

松下这次更新的L.单色D黑白滤镜，是属于反差适中，过渡强烈的类型，比起高反差滤镜，松下会有更多的细节和更细腻的过渡。而比起ACROS这类以细腻、平缓著称的滤镜，松下则会有更强烈的对比和灰阶过渡。总之是一个很有趣的新滤镜。

总结 编辑眼中最好的便携相机 或许是1英寸便携机杀手

LX100发布之后，就吸引了不少忠实的粉丝，在这个规格的相机中，实用的家庭用户占了不小的部分，但更细分来说占据着实用家庭用户中对相机颇有要求的一部群体。这个群体并非单纯的参数党，他们或多或少对相机已经有深入的了解，只是平衡自己的需求来选择适合的相机，并非狂热的追求某一方面的性能及参数。

LX100 Mark Ⅱ综合来说，是当前不可换镜头&变焦相机中，体积适宜、画质优秀、操控非常流畅的一款产品，如果售价并没有太大的区别，或者还有优势的话，我觉得LX100 Mark Ⅱ比起一众1英寸便携相机来说，竞争力更明显一些。
