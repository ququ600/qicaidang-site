多媒体单反时代 尼康D90试用报告（二）

2008-09-18 · Wayback 存档 · 原站地址

规格参数：

镜头卡口：尼康F卡口(带AF耦合和AF接点)

有效画角：约1.5倍镜头焦距(尼康DX格式)

有效像素：1230万

影像传感器：1290万像素，23.6×15.8mm CMOS传感器

除尘系统：影像传感器除尘功能，影像除尘参考数据(需配合另购的Capture NX 2)

影像尺寸：4288×2848，3216×2136，2144×1424

文件格式：NEF(RAW)、JPEG：精细(约1：4)，标准(约1：8)压缩，基本(约1：16)

优化校准系统：标准、自然、鲜艳、黑白、人像、风景模式

存储介质：SD存储卡，兼容SDHC

文件系统：DCF(Design Rule for Camera File System，相机文件系统设计规则)2.0，DPOF (Digital Print Order Format，数码打印指令格式)，Exif 2.21(Exchangeable Image File Format for Digital Still Cameras，数码相机用可交换影像文件格式)，PictBridge

取景器：眼平五棱镜单镜头反光取景器

画面覆盖率：约96%(垂直与水平方向)

画面放大率：约0.94倍(将50mm f/1.4镜头设定为无限；屈光度为-1.0m-1)

视点：19.5mm(-1.0m-1)

屈光度调整：-2至+1m-1

对焦屏：带对焦框的B型光亮磨砂对焦屏Mark II(可显示取景网格)

反光镜：快速返回型

景深预览：按下相机景深预览按钮时，镜头光圈会缩小为用户(A和M模式)或相机(其他模式)选择的数值。

镜头光圈：即时返回型，电子控制

快门类型：电子操控纵走式焦平面快门

快门速度：1/4000-30秒范围(以1/3或1/2 EV为步长调校、B门

闪光灯同步速度：X=1/200秒；在1/200秒或以下速度时，与快门保持同步

快门释放模式：单张拍摄、低速连拍、高速连拍、自拍、延时遥控、快速响应

每秒拍摄速度：高速连拍(每秒最多约4.5 幅)

低速连拍(每秒约1-4幅)

自拍：可选择2秒、5秒、10秒和20秒延时

测光：使用420区RGB传感器进行TTL曝光测光

测光系统：矩阵测光：3D彩色矩阵测光II(G型和D型镜头)；彩色矩阵测光II(其他CPU镜头)

中央重点测光：约75%的比重分布于画面中央的6、8或10mm直径圆形内

点测光：集中在以选定对焦点为中心的3.5mm直径圈中(约为画面的2%)

测光范围：(ISO100相当值，f/1.4镜头，20°C)

矩阵或中心重点测光：0-2 EV

点测光：2-2 EV

曝光测光耦合：CPU

曝光模式：自动模式(自动、自动[闪光灯关闭])、场景模式(人像、风景、运动、近摄、夜间人像)、带柔性程序的程序P、快门优先S、光圈优先A、手动M

曝光补偿：以1/3或1/2 EV步长在-5 EV和5 EV之间调校

曝光包围：拍摄2或3幅，以1/3、1/2、2/3、1或2 EV为步长调校

曝光锁定：光亮度锁定在使用AE-L/AF-L按钮所测定的值上

ISO感光度：ISO 200-3200，以1/3 EV为步长调校；ISO 200以下时，感光度以约0.3、0.7或1 EV (ISO 100相当值)作定级递减；高于ISO 3200时，感光度以约0.3、0.7或1 EV(ISO 6400 相当值)作定级递增。

动态D-Lighting：自动、极高、高、标准、低或关闭

动态D-Lighting包围：2幅

自动对焦：尼康Multi-CAM 1000自动对焦模块具备TTL相位侦测，11个对焦点(包括1个十字型传感器)和自动对焦辅助照明灯(范围约为0.5-3m)

侦测范围：-1至+19 EV(ISO 100相当值，20°C)

镜头伺服：自动对焦(单次伺服AF-S、连续伺服AF-C、自动伺服AF-A；预测性焦点追踪功能，会根据单次及连续伺服AF自动启动)

手动对焦：支持电子测距仪

对焦点：从11个对焦点中选择

AF区域模式：单点AF、动态区域AF、自动区域AF、3D追踪(11点)AF

焦点锁定：通过半按释放按钮(单次伺服自动对焦)或按下AE-L/AF-L按钮锁定对焦

内置闪光灯：自动、人像、近摄、夜间人像模式、自动弹出型自动闪光

P、 S、 A、 M：按下释放按钮手动弹出闪光灯

闪光指数：在ISO 200时：约17(手动闪光时为18)

在ISO 100时：约12(手动闪光时为13)

闪光控制：TTL：使用420区RGB传感器进行针对数码单反相机i-TTL均衡补充闪光和标准i-TTL闪光，这些方式适用于内置闪光灯和SB-900、SB-600或SB-400闪光灯

自动光圈：适用于SB-900闪光灯及CPU镜头

非TTL自动闪光：支持SB-900、SB-28、SB-27或SB-22s闪光灯组件

距离优先手动：适用于SB-900

闪光模式：前帘同步、慢速同步、后帘同步、减轻红眼、减轻红眼慢速同步

闪光补偿：以1/3或1/2EV为步长在-3至+1 EV之间调校

闪光包围：2至3幅，以1/3、1/2、2/3、1或2 EV步长调校

闪光预备指示灯：当内置闪光灯或SB-900、SB-600、SB-400、SB-80DX、SB-28DX或SB-50DX闪光灯完全充电后，指示灯亮起；当闪光灯在i-TTL或自动光圈模式闪光下以全光输出后将闪烁约3秒

配件热靴：带安全锁的标准ISO 518热靴接点

尼康创意闪光系统(CLS)：使用内置闪光灯、SB-900或SU-800作为指令器，以及SB-900、SB-600或SB-R200作为遥控装置时，支持高级无线闪光；SB-400以外的所有CLS兼容闪光灯组件都支持自动FP高速同步和模拟照明；所有CLS兼容闪光灯组件都支持闪光色彩信息交流和FV锁定

白平衡：自动(具有主影像传感器和420区RGB传感器的TTL白平衡)；带有微调的12种手动模式；色温设定；预设手动白平衡

白平衡包围：2或3幅，以1、2或3 EV为步长调校

即时取景AF模式：脸部优先AF、宽区域AF、标准区域AF

对焦：可在画面任意位置进行对比度侦测AF(选择脸部优先AF时，相机自动选择对焦点)

短片影像尺寸：1280×720/24 fps、640×424/24 fps、320×216/24 fps

文件格式：AVI格式

压缩格式：动态JPEG 格式，单声道音频

LCD显示屏：3英寸，约92万画点(VGA)、约170°视角的低温多晶硅TFT LCD显示屏，约100%画面覆盖率，可进行亮度调节

播放功能：支持变焦播放的全屏和缩略图(4、9或72张影像或日历)播放、短片播放、Pictmotion、幻灯播放、直方图显示、高亮显示、自动旋转影像及影像注释(最长可达36个字符)

USB：高速USB

音频/视频输出：NTSC和PAL 制式，音频/视频输出设备和相机LCD显示屏可同时进行播放

HDMI输出：HDMI迷你接口，HDMI线接入时，相机显示屏将会关闭

支持语言：中文(简体和繁体)、丹麦语、荷兰语、英语、芬兰语、法语、德语、意大利语、日语、韩语、挪威语、波兰语、葡萄牙语、俄语、西班牙语、瑞典语

电池：1节EN-EL3e锂离子充电电池

电池盒：多功能电池匣MB-D80(另购)，可装入1或2节可充电锂离子充电电池EN-EL3e或6节AA 碱性电池、镍氢电池、锂电池或镍锰电池(当使用AA碱性电池时需要使用MS-D200电池匣)

交流电源适配器：交流电源适配器EH-5a(另购)

三脚架连接孔：1/4英寸(ISO 1222)

尺寸：约132×103×77mm

重量：约620g(不包括电池、存储卡、机身盖和显示屏盖)

附件配件(可能会因国家和地区而异)：可充电锂离子电池EN-EL3e、快速充电器MH-18a、目镜盖DK-5、橡胶眼罩DK-21、USB连接线UC-E4、音频/视频线EG-D2、相机背带AN-DC1、LCD显示屏盖BM-10、机身罩、配件热靴盖BS-1、Software Suite CD-ROM光盘

参考价格：套机9500元(AF-S DX 18-105mm f/3.5-5.6G ED VR）
