动静两相宜 佳能PowerShot G7 X Mark III试用评测

2019-08-21 · Wayback 存档 · 原站地址

写在前面

当年，G系列作为佳能卡片机系列当中的专业级相机，拥有让人为之惊叹的专业度，准专业的黑色机身，各种模式拨盘，手感甚至与专业单反机不无二致，因此一度风靡摄友圈，圈粉无数。

PowerShot G9

2012年初，佳能发布了第一款以X命名的G系列机型——PowerShot G1 X。准专业级的外形配以1.5英寸的大尺寸感光元件，预示着佳能将在G系列上发力。果不其然，2014年初PowerShot G1 X Mark II发布，依旧是1.5英寸，很多人都预感G系列将会往更大画幅甚至是全画幅方向发展。

PowerShot G1 X

PowerShot G1 X Mark II

可就在同年9月，PowerShot G7 X横空出世！在当时看来，这是一台完全与G系列不搭调的机器。扁平化的机身设计、小巧轻薄，取消了取景器等专业元素，更像是轻薄的卡片机。

佳能推出PowerShot G7 X的意义何在？首先，随着时代的前进，人们对于相机的需求不再单单是“傻大黑粗”的专业气质，而是开始趋于多元化，这种变化促使着器材厂商开始改变自己固有的设计思路。其次，佳能已经开始对G系列重新布局，PowerShot G7 X就是这个布局中的先锋官。

PowerShot G7 X

虽然发布初期受到了一定的质疑，但PowerShot G7 X最终还是被用户接受并认可，这是佳能在专业便携机领域战略上的成功。

2019年7月，佳能发布了最新一代的G7 X——PowerShot G7 X Mark III。5年时间里，历经3代机型的蜕变，PowerShot G7 X Mark III已经不再是刚刚推出时的试水机型，它兼顾性能、便携与时尚，它不再需要被认可，它早已是当之无愧的便携街拍利器。

PowerShot G7 X Mark III
