外媒公布适马14-24/2.8A的MTF测试结果

2018-07-30 · Wayback 存档 · 原站地址

大多数人都知道Roger Cicala是适马的Art 定焦镜头的忠实粉丝。 适马几乎每时每刻都能以优惠的价格提供优质的光学素质。 但Roger Cicala对适马Art变焦镜头的看法是喜忧参半的。 他认为适马 24-105mm f / 4 Art是他测试过的最好的24-105mm（虽然他讨厌测试任何24-105）。 另一方面，适马24-70mm f / 2.8ART它认为是足够的。

Roger Cicala不确定对适马 14-24mm f / 2.8 DG HSM Art有什么期望，所以他很想测试这款镜头并在库存中立即选取了测试副本。

关于镜头

几年前，尼康推出了14-24mm f2.8G ED镜头。这是一场革命，它比当时市面上任何广角变焦都更宽更锐利。多年来它一直是广角变焦的黄金标准。适马这次并没有填补空白，尼康已经有一个优秀14-24mm，腾龙有一个不太广，但焦距接近的15-30mm f / 2.8VC。

适马比尼康便宜400美元，但比腾龙15-30mm f / 2.8 Di VC 贵200美元。适马（1150克）比尼康（1000克）重一点，与腾龙（1100克）大致相同。

所以规格来看适马应该和尼康14-24mm一样好，比腾龙15-30好。这是一项艰巨的测试任务。是的，会有人希望加入其它广角变焦测试。首先，f / 4不是f / 2.8。其次，16mm不是14mm，它们是非常不同的（更不用说，大多数16-35mm实际上（广角）只有17mm）。

一个免责声明

当然，通常的'这不是镜头完整评测，它只是MTF光学测试部分。该测试针对比16mm更广的全画幅f / 2.8镜头。另外，需要提及的是要么测试是正确的，要么可能超过测试机器的极限。这个测试复杂的，它是有争议的，但值得一提的是，你应该考虑这篇文章中的图表，它可能不精确描述外边缘。

另外，第一次违反了通常的测试协议，此次向你展示的测试是第二套10个镜头，而不是前10个。如果你有兴趣了解为什么你可以在附录中阅读到原因。

光学测试

正如此前测试2倍变焦镜头的做法一样，这些镜头在两端进行了测试（在3倍和更大倍率变焦镜头上测试中间焦距）。首先，让需要提一下镜头的实际焦距是14.3mm到23mm。之所以提到这一点，是因为它的数据不是注水的;（+/- 5％是变焦的标准配置）。畸变也是合理的：14mm时为0.8％，24mm时为1.1％。在两端，畸变是较好的，有点像蔡司21mm f / 2.8。

适马 14-24mm f / 2.8 DG HSM Art MTF

14mm

这是一个很好的表现。 大约在边缘的一半处，我们开始看到实线和虚线出现一些像散分离（也可能是横向色差）。

正如上面提到的，14mm全画幅镜头正处于我们测试机器自动化的极限。 你可能注意到距离轴4mm处的切向MTF的下降可能是受到影响; 对于非常广角镜头，不会向你提供有关失真被映射到不足点的细节。 它也可能是由非球面镜片引起的。 我不能肯定地说。

24ｍｍ

24mm处分辨率甚至更好，在整个画面都非常出色。

收缩光圈MTF

之前的测试图是在最大光圈下测试的所有十个样本的平均值。 拿了其中一个典型的样本收缩光圈进行重新测试。 与f / 2.8相比，f / 4处的分辨率有显着提升。 f / 4和f5.6之间几乎没有变化，所以我不打算上f5.6的图。 14mm

24mm

您可能会注意到MTF图中f / 4时的边缘看起来有点差。 这是一个复杂的事情，涉及畸变，镜头的场曲率和机器焦点的变化，并不是真实的体现。

MTF横向比较

尼康14-24mm f / 2.8G ED

首先用适马与长期的黄金标准尼康14-24 f / 2.8G ED进行比较。 当然，尼康是一个更老的设计，但现在仍然是一个极好的镜头。

14ｍｍ

两款镜头中心都非常出色。 在外1/3处，尼康实现和虚线分离更小（焦外更好），适马则拥有更高的分辨率。 这会对你的实际拍摄产生影响吗？ 通过仔细比较，您可能会注意到适马具有更好的边角分辨率，但更乱的焦外很难看出任何差异。

24ｍｍ

在24ｍｍ处，适马凸显出相对其他产品的优势。 适马在各处都比较清晰。 当然，这种差异应该是显而易见的。

腾龙15-30mm f / 2.8 Vi DC USD

14mm VS15mm

腾龙在广角端是一款出色的镜头，非常适合尼康。适马在中心可能会更好一些; 腾龙在边缘可能会好一些。 但是，机器再一次在这里限制了测试能力，所以不能说有任何明显的区别。

24mm对30mm

和此前测试一样，适马在长焦端明显更好。

如果你想要一个非常好的例子来说明14mm的多难做，这里是适马14-24mm f / 2.8和佳能14mm f / 2.8 的比较。 在某种情况下，变焦可能比定焦更好。

如果你觉得佳能不是最好的14mm定焦; 选择最好的14mm定焦适马14mm f1.8 Art。 在f2.8时比任何其他都好。 所以变焦不如定焦是正确的。

结论

在开始时说过，预计这款镜头至少和尼康14-24mm f / 2.8一样好，而且比腾龙15-30mm f / 2.8要好。最终测试来看它们在14mm处差距不大，但适马在24mm处表现最好。在光学上，这是整体最好的14-24ｍｍ变焦，对得起价格。

话虽如此，如果你想购买一个14ｍｍ镜头作为14ｍｍ定焦（你们中的一些人），那么这三个镜头都做得非常好。但老实说，如果是这样的话，你应该考虑一下适马14mm f / 1.8 Art。如果您正在考虑将14-24mm f / 2.8与24-70mm f / 2.8组合覆盖整个焦距，那么适马是最佳的选择。

要提两件事。首先，对于希望将其与16-35进行比较的，这不是一个公平的比较，不打算这样做。 14mm与16mm非常不同;设计和制造14mm更加困难。如果16-35mm能够满足您的需求，并保持很好滤镜兼容性，那还是购买16-35mm吧。
