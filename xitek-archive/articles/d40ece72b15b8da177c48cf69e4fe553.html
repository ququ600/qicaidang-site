Lexar Image Rescue 3.0数据保护神

2008-10-09 · Wayback 存档 · 原站地址

存储已不再是专业摄影师、摄影记者们的专利。如今，普通消费者也在“记录感动，存储记忆”，只要举起数码相机或拍照手机，就可以收录精彩瞬间。很多人认为：一款数码相机+1张存储卡+1个读卡器=存储。其实不然，如果刚拍的图片不小心在相机上删除了，时过境迁，无法重来，怎么办？全球领先的存储产品供应商Lexar Media（雷克沙）提供的Image Rescue 3.0图像恢复软件，同时为您带来全新的的存储理念：完美存储=一款数码相机+1张存储卡+1个读卡器+ Lexar Image Rescue 3.0。

Lexar Image Rescue 3.0 软件

Lexar Image Rescue软件是Lexar Media（雷克沙）推出的一款简单易用的图像恢复软件。它不局限于存储卡的格式、品牌，支持任何读卡器，3.0版本不但可以帮助用户恢复任何类型 / 格式的存储卡中的照片文件，还能够恢复视频、音频等文件，对数据拥有无比强大的恢复能力。而且，它还支持CD刻录，能把丢失的文件永久保留下来。下面就一起来体会一下Lexar Image Rescue 3.0软件试用的全过程——

安装并运行Lexar Image Rescue 3.0软件

Lexar Image Rescue 3.0软件分为Windows和Mac-OS-X两个版本。安装运行都非常简单、易操作。如上图左侧，运行后它会清楚地标出5个步骤，包括：选择存储卡（Select Card）、选择文件类型（File Types）、查找图片（Find Images）、预览图片（Preview Images）和保存图片（Save Images）。最后一个就是CD刻录，刻录图片功能（Burn Images）可把丢失的文件保存到CD光盘上。

选择存储卡

首先是选择需要恢复图片的存储卡。如上图，运行Lexar Image Rescue 3.0软件后，它会自动显示电脑G盘上的Lexar 2GB 133X Professional SD存储卡。如果电脑上插有多个存储卡，可能出现多个存储卡信息，这样就需要选择存储卡（Select Card）——选择需要恢复丢失文件的卡。

选择恢复文件的类型

下面的环节是根据丢失文件的类型，图片、视频或音频，选择不同的格式。如上图，点开“ ② File Types（文件类型） ”，选择丢失文件类型，如选择JPG格式的图片、MOV格式的视频以及MP3格式的音频。通过上图的信息，我们也可以了解到Lexar Image Rescue 3.0支持的相机品牌非常齐全，包括了尼康、佳能、柯达、富士、奥林巴斯、适马、卡西欧、惠普、宾得、索尼等众多品牌的数码相机。

开始恢复丢失文件

在“ ③ Find Images（查找图片） ”步骤里，点击Start（开始），开始恢复丢失的文件，而且恢复的速度非常快。在不到3秒的时间里，已经成功找到了18个文件。如果丢失的文件已经全部恢复完毕后，则可以停止恢复，进入图片预览步骤。

成功恢复丢失的图片

在“④ Preview Images（图片预览） ”里，如上图，看到了已经成功恢复的图片。接下来可以逐个浏览已经恢复的文件，然后进入下一步，保存图片。

放大恢复图片

在图片预览中，每个图片下方都有放大和选择按钮，这种设置是非常人性化的，以便更好地查看和选择保存。

保存恢复图片

Save Image（保存图片），可以选择需要保存的路径，如果不做选择，Lexar Image Rescue 3.0 会自动把需要保存的文件保存在电脑的图片文件夹里。还可以为新建的文件夹输入自己想要的名字，以方便在电脑上轻松找到。其实Lexar Image Rescue 3.0软件还有更周到的设置，就是点击运行界面里的“Open”，软件会直接打开已经成功保存图片的文件夹。（如下图）

打开保存图片的文件夹

从选择存储卡（Select Card）开始，一直到选择文件类型（File Types）、查找图片（Find Images）、预览图片（Preview Images）和保存图片（Save Images），轻松点击，五部完成。然而，刻录图片（Burn Images）的功能，让人不得不佩服Lexar（雷克沙）作为全球领先存储品牌的周到细致服务。为了避免文件的再次丢失，Lexar Image Rescue 3.0软件会建议把恢复的文件刻录到CD光盘上，确保万无一失，杜绝后患，让用户彻底无后顾之忧。

将恢复的图片刻录到CD光盘

此外，Lexar Image Rescue 3.0软件还可以对存储卡进行重新格式化、安全删除图片、提供全面检测报告等操作，确保存储卡一直处于理想的工作状态。

无论是专业摄影师，还是家用数码相机的使用者，图像恢复软件对于恢复照片来说都是至关重要的。作为Lexar存储卡的完美补充，Lexar Image Rescue 3.0软件带来的不仅仅是恢复图片时的惊喜，更多的是一种一站式存储的完美理念。值得一提的是，目前所有购买Lexar Platinum II（白金二代）和Professional（专业系列）存储卡的用户，都可以在指定网址免费下载到此款软件。拥有完美的存储理念，就先从拥有Lexar存储卡和Lexar Image Rescue 3.0软件开始吧！
