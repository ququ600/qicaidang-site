EOS 60Da

3.75综合评分
分类 APS及其以下画幅可换镜头数码相机点评 0 条图片 0 张评测 0 篇

EOS 60Da和普通版EOS60D最大的区别在于CMOS图像传感器前部端配备的特制低通滤镜 (Low Pass Filter)，可让星云所发出的红色可见光Hydrogen Alpha射线更容易地传达到 CMOS之上，敏感度可以达到一般佳能数码单反相机的3倍左右。这样就可以将α波长的感光率提升20%，拍出的星云效果能得到较佳的反差及锐利度。
